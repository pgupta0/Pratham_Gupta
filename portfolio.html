Transit One

B2B transport marketplace · built solo
Prototype
Problem

Corporates booking freight negotiate rates over calls and email, one truck at a time, with no price discovery and no way to compare fleet operators against each other.

Build

A two-sided marketplace: corporates post a route, verified fleet operators bid on it. I built the pricing model, the tiering logic and both user journeys end to end.

State today

Working interactive prototype, mobile-first. Not yet handling live payments or contracts — the next commit would be operator verification.

FinBuddy

RAG-based portfolio assistant · shipped & live
Live
Problem

First-time Indian investors get either a generic robo-advisor with no explanation, or a model that hallucinates fund recommendations with no source behind them.

Build

A short risk quiz scores the investor, then a retrieval layer pulls real, cited fund data instead of letting the model guess, before it generates an allocation.

State today

Live and public. Chats run entirely client-side via localStorage, which is why it opens in its own tab rather than an embedded frame here.

v0.9.0 · CONCEPT SIMULATION

Crave Command Center

Live food-delivery operations map
Concept sim
Problem

Dispatchers running a delivery network can't see rider load, relay handovers or which operating model is winning — that all lives in separate dashboards, after the fact.

Build

A live operations map simulating five operating models at once, with riders moving in real time, relay handovers between them, and a KPI terminal overlaid on top.

State today

Concept work, not a real product or real data. Built to explore what a live-ops control surface could feel like.
